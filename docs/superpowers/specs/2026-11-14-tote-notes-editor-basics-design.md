# tote-notes 편집기 기본기 설계 — 대괄호 짝, 줄 바꿈 토글, 들여쓰기, 글자 수, 접기

2026-11-14. 기능 묶음(공통 계약: 코디네이터의 `.superpowers/handoff/features-common.md`)의 하나다. 사용자가 설계 확인 없이 바로 진행하라고 했다. 그래서 동작·기본값은 **코디네이터의 판단**이고, 브리프가 비운 세부는 **구현자의 판단**이다. 결정마다 출처를 붙인다 — 사용자가 읽고 바꿀 수 있게.

## 왜

편집기(`src/editor/setup.ts`, CodeMirror 6)에 흔한 편집기 기본기가 없었다.

- 대괄호 짝이 보이지 않는다.
- 줄 바꿈은 늘 켜져 있고(한 줄이 2만 자를 넘으면 꺼진다) 끌 수 없다.
- 들여쓰기는 CodeMirror 기본값(공백 2, 탭 너비 4)이고 바꿀 수 없다.
- 글자 수를 볼 수 없다.
- 접기가 없다.

## 목표

1. 커서 옆 대괄호의 짝을 강조한다. 늘 켜져 있다.
2. 줄 바꿈을 설정과 메뉴 「보기 › 줄 바꿈」(⌥Z)으로 켜고 끈다.
3. 들여쓰기를 「공백 2 · 공백 4 · 탭」 가운데서 고른다.
4. 상태 표시줄에 글자 수(선택이 있으면 선택한 글자 수)를 보일 수 있다.
5. 줄번호 옆 접기 표시와 키로 블록을 접고 편다.

## 하지 않는 것

코디네이터의 판단: 들여쓰기 자동 감지(파일에서 추측하기), 공백 문자 표시, 미니맵, 접은 상태 저장(세션), 단어 수.

## 하면 실패인 것

- 업데이트만으로 사용자가 보는 것이 바뀐다 — 새 설정의 기본값은 지금 동작과 같다(글자 수만 기본 끔이라 상태 표시줄도 그대로다).
- 글자 수 세기가 타이핑을 늦춘다.
- 2만 자 넘는 줄이 있는 파일에서 줄 바꿈이 켜진다(설정이 켜져 있어도).

## 대괄호 짝

- CodeMirror `bracketMatching()` 을 늘 켠다. 설정은 없다(코디네이터의 판단).
- 커서 바로 앞이나 뒤의 `()` `[]` `{}` 와 그 짝을 칠한다(`.cm-matchingBracket`). 짝이 없으면 그 괄호를 경고 색으로 칠한다(`.cm-nonmatchingBracket`).
- TextMate 문법은 구문 트리를 주지 않으므로 CodeMirror 의 글자 훑기로 짝을 찾는다(앞뒤 10,000자까지, CodeMirror 기본). 그래서 문자열·주석 속 괄호도 짝으로 센다. 마크다운은 번들 파서의 트리를 쓴다.
- 색은 테마 변수다(구현자의 판단): 배경 `--bracket-match`(VS Code `editorBracketMatch.background`), 테두리 `--bracket-match-border`(`editorBracketMatch.border`). 짝 없는 괄호는 글자를 `--danger` 로 칠한다. 기본값과 대비:

| 변수                     | 라이트               | 다크                    | 대비(구현자의 판단)                                        |
| ------------------------ | -------------------- | ----------------------- | ---------------------------------------------------------- |
| `--bracket-match`        | `rgb(0 100 0 / 10%)` | `rgb(80 200 120 / 16%)` | 그 위의 본문 글자(`--fg`)가 4.5:1 이상                     |
| `--bracket-match-border` | `#6e7781`            | `#8b9099`               | 편집기 배경(`--bg`)에 3:1 이상(글자 아닌 표시의 WCAG 기준) |

`src/theme/vscode-theme.test.ts` 가 두 모양 모두 이 대비를 단언한다.

## 줄 바꿈

- 설정 「모양 › 편집기 › 줄 바꿈」, 기본 **켬**(지금 동작). settings.json `editor.wrap`.
- 메뉴 「보기 › 줄 바꿈」 — 체크 표시가 있는 항목이고 설정을 바꾼다(코디네이터의 판단). 모든 창·모든 탭에 바로 적용되고 저장된다. 기본 단축키 **⌥Z**(VS Code 와 같다).
- **2만 자 넘는 줄이 있는 탭은 설정이 켜져 있어도 줄 바꿈이 꺼진다**(지금 규칙, `WRAP_LIMIT`). 판정은 지금처럼 탭의 글을 읽을 때 한 번이다. 설정을 껐다 켜도 그 탭은 꺼진 채다.
- 동작: 메뉴 항목은 앞 창의 페이지로 `tote://menu` `toggle-wrap` 을 보내고, 페이지가 `editorWrap: !지금 값` 으로 설정을 고친다. 백엔드는 설정 변경을 모든 창에 알리고(`tote://config`), 메뉴의 체크 표시를 저장된 값에 맞춘다(`menu::follow_checks`). macOS 가 누를 때 체크를 저절로 뒤집으므로, 메뉴 항목을 누를 때마다 체크를 저장된 값으로 먼저 되돌린다 — 페이지가 설정을 고치지 못하면(창이 없을 때 등) 체크가 설정과 어긋나지 않게(구현자의 판단).
- 열린 탭에는 편집기 상태를 다시 짠다(줄번호 설정과 같은 방식, 보이지 않는 탭까지).

### ⌥Z 와 겹침

- 다른 앱 명령의 기본값·고정 단축키(`FIXED`)에 ⌥Z 는 없다.
- 편집기 키맵(`editorKeymap`)에 `Alt-z` 는 없다. 그래서 편집기가 그 키를 받지 않고 메뉴가 받는다.
- ⌥Z 는 앱 명령 기본값 가운데 ⌘ 없는 첫 단축키다. WKWebView 는 키를 페이지에 먼저 주므로, ⌥Z 가 글자 입력으로 먼저 소비되면 메뉴가 불리지 않는다 — 실제 앱에서 메뉴로 가는지는 화면 확인 전이다. 안 되면 기본 키를 ⌘ 조합으로 바꾸거나 `menuKeymap` 이 편집기에서 ⌥Z 를 받아 명령을 돌리게 한다.
- macOS: ⌥Z 는 시스템 단축키가 아니다. 미국 자판에서 ⌥Z 는 `Ω` 를 치는 키이므로 이 단축키가 있는 동안 편집기에서 ⌥Z 로 `Ω` 를 칠 수 없다(VS Code 와 같다). 설정 › 단축키에서 지우거나 바꿀 수 있다.
- 줄 바꿈은 이미 사람들이 단축키를 저장한 뒤에 들어온 명령이라 **양보하는 기본값**(`yielding`)이다: 다른 명령에 ⌥Z 를 적어 둔 사람은 그 키가 이기고 줄 바꿈은 키 없이 시작한다(빠른 열기 ⌘P 와 같은 규칙).
- 같은 차례의 다른 작업이 명령·단축키를 더한다. 병합 때 ⌥Z 와 겹치지 않는지 다시 본다(코디네이터).

## 들여쓰기

- 설정 「모양 › 편집기 › 들여쓰기」 고르개: 「공백 2 · 공백 4 · 탭」. settings.json `editor.indent` 값 `"spaces-2"` · `"spaces-4"` · `"tab"`.
- 기본은 **공백 2** — 지금 동작이다(코디네이터의 판단, 값은 구현자가 확인: 앱이 `indentUnit` 을 정하지 않아 CodeMirror 기본 `"  "` 이고, `tabSize` 도 기본 4다).
- 따르는 것: Tab 키(`insertIndent` — 커서마다 한 단위, 선택이 있으면 그 줄들을 한 단위 들임), ⇧Tab(`indentLess`), ↩ 의 자동 들여쓰기(`insertNewlineAndIndent` — 윗줄의 들여쓰기 너비를 이 단위로 다시 쓴다. 「탭」 이면 탭 문자로), CodeMirror 의 `indentUnit`.
- 탭 문자의 보이는 너비(`tabSize`)는 언제나 4다. 브리프는 「탭」 일 때 4를 정했고, 공백일 때도 지금 값(CodeMirror 기본 4)을 그대로 둔다(구현자의 판단 — 공백 설정에서 탭 문자 너비가 바뀌면 지금 보이는 파일 모양이 바뀐다).
- 언어 기여의 `language-configuration.json` 에서 지금 쓰는 들여쓰기 규칙은 없다(`indentationRules`·`onEnterRules` 를 읽지 않는다, `src/editor/language-config.ts`). 그대로 둔다. 마크다운 목록 이어 쓰기는 번들 파서가 맡고, 들여쓰기 단위는 이 설정을 따른다.
- 파일의 들여쓰기를 추측하지 않는다(넘기는 것).

## 글자 수

- 설정 「모양 › 편집기 › 글자 수 보이기」, 기본 **끔**(코디네이터의 판단 — 업데이트만으로 상태 표시줄 모양이 바뀌지 않게). 꺼져 있으면 그 칸은 레이아웃에 없다 — 줄·열과 언어 사이 간격이 업데이트 전과 같다. 저장된 값은 창이 뜰 때부터 따른다. settings.json `editor.charCount`.
- 켜면 상태 표시줄의 줄·열 오른쪽에 문서의 글자 수를 `1,234자` 로 보인다. 선택이 있으면 `선택 12자` 로 바꿔 보인다. 선택이 여럿이면 합이다(빈 선택 — 커서 — 은 0).
- **사람이 보는 글자(grapheme)** 로 센다(`Intl.Segmenter`, 코디네이터의 판단): 조합 중인 한글 한 음절, 첫가끝 자모로 된 음절, 피부색·ZWJ 이모지, 국기가 각각 한 글자다.
- **줄바꿈은 세지 않는다. 공백과 탭은 센다**(구현자의 판단 — 워드·한글(HWP)의 「공백 포함 글자 수」 와 같다).
- **100만 글자(UTF-16 단위)를 넘는 문서는 세지 않고 보이지 않는다**(코디네이터: 1MB. 단위는 메모 저장 간격의 1MB 와 같은 `LARGE_MEMO_CHARS` 관례 — 바이트를 세는 것 자체가 비싸다, 구현자의 판단). 선택이 있어도 마찬가지다.
- 타이핑을 늦추지 않게 세기는 입력 경로에서 뗀다(`src/editor/char-count.ts` `CharCounter`): 글이나 선택이 바뀌면 0.2초 쉰 뒤에 세고, 세는 동안 8ms 마다 다음 작업으로 넘겨 프레임을 막지 않는다. 넘기는 자리는 줄 사이와, 4,096자 넘는 줄 안의 공백 앞이다 — 공백 앞에서는 사람이 보는 글자가 갈리지 않는다. 공백 없이 긴 줄은 통째로 센다. 그 사이에 또 바뀌면 세던 것을 버리고 다시 기다린다. 커서만 움직이면 이미 센 문서 수를 그대로 쓴다. 고치는 동안에는 셀 때까지 앞 숫자가 남고, 다른 탭으로 바꾸면 셀 때까지 비운다(다른 탭의 숫자가 남지 않게, 구현자의 판단).
- 휴지통 메모(읽기 전용)에서도 센다. 대용량 텍스트 뷰어·미디어 뷰어에는 없다(편집기가 아니다).

## 접기

- 줄번호 오른쪽에 접기 표시(`foldGutter`: 접을 수 있는 줄에 `⌄`, 접힌 줄에 `›`)를 둔다. 누르면 접고 편다. 접힌 자리에는 `…` 표시가 남고 누르면 편다.
- 설정 「모양 › 편집기 › 접기 표시」, 기본 **켬**(코디네이터의 판단). settings.json `editor.foldGutter`. 끄면 표시만 사라지고 키로는 접힌다.
- 줄번호를 꺼도 접기 표시는 보인다 — 접기 표시만의 좁은 칸(코디네이터의 판단, 그대로 따랐다).
- 키(CodeMirror `foldKeymap` 그대로): **⌥⌘[** 접기, **⌥⌘]** 펴기, **⌃⌥[** 모두 접기, **⌃⌥]** 모두 펴기. 편집기 키라서 설정 › 단축키의 편집기 키 표에 들어간다(`src/shortcuts/command-names.ts` 에 `foldCode`·`unfoldCode`·`foldAll`·`unfoldAll`). 앱 명령의 기본값·고정 단축키와 겹치지 않는다(탭 이동은 ⇧⌘[·⇧⌘], 칸 이동은 ⌥⌘방향키).
- 범위(코디네이터의 판단: TextMate 문법은 범위를 주지 않는다):
  - **들여쓰기 기반 접기**를 모든 언어에 쓴다(`src/editor/folding.ts` `indentFold`). 비지 않은 줄 다음의 첫 비지 않은 줄이 더 깊이 들여써져 있으면, 그 줄 끝부터 들여쓰기가 처음 줄 이하로 돌아오기 전의 마지막 비지 않은 줄 끝까지 접는다. 빈 줄은 들여쓰기를 따지지 않고 블록 끝에 매달린 빈 줄은 접지 않는다. 탭은 `tabSize`(4) 너비로 센다. 다음 글 있는 줄이 `FOLD_LOOKAHEAD_LINES`(1,000줄) 안에 없으면(빈 줄만 이어지면) 접지 않는다(구현자의 판단 — 빈 줄을 끝없이 훑지 않게).
  - **마크다운**의 제목은 번들 `@codemirror/lang-markdown` 파서가 먼저 접는다: 다음 같거나 높은 제목 앞까지. 제목이 아닌 줄은 들여쓰기 범위가 먼저이고, 그것이 없을 때 파서의 구문 접기(코드 블록·인용·표·여러 줄 문단)를 쓴다 — CodeMirror 는 접기 서비스(제목·들여쓰기)를 모두 물은 뒤에야 구문 접기를 본다. 그래서 펜스 안 코드가 들여써져 있으면 들여쓰기 범위(닫는 펜스 앞까지)로 접힌다. 마크다운에 들여쓰기 접기를 더한 것은 구현자의 판단이다 — 빼면 중첩 목록을 접을 수 없다.
  - **접기 표시는 블록 끝을 찾지 않는다**(구현자의 판단). 접기 표시는 글이 바뀔 때마다 보이는 줄마다 「접을 수 있나」 를 다시 묻는다. 그때 들여쓰기 접기는 다음 글 있는 줄이 더 깊은지만 보고(`probeFold`), 블록 끝은 표시를 누르거나 접기 키를 누를 때 한 번 찾는다. 그래서 블록 길이에 한도가 없고, 깊게 중첩된 큰 파일(맨 안쪽 배열이 수만 줄인 JSON)의 맨 위에서 쳐도 키마다 블록 끝까지 훑지 않는다. CodeMirror 의 `foldGutter` 는 표시 판정에 범위 전체를 구하므로, 같은 모양·동작의 거터(`foldMarkers`)를 따로 둔다.
- 접은 상태는 세션에 남기지 않는다(넘기는 것). 탭을 닫았다 열거나 앱을 다시 띄우면 펴져 있다.
- **글이 2,000만 글자(`HIGHLIGHT_LIMIT_CHARS`)를 넘는 탭은 접기를 끈다** — 표시도 키도(코디네이터의 판단, 하이라이트를 끄는 경계와 같다). 판정은 하이라이트처럼 탭의 글을 읽을 때 한 번이다.
- 접힌 블록 위에서 줄번호를 누르면 블록의 모든 줄이 한 단위로 골라진다(줄번호 선택의 `spanOf` 가 이미 그렇게 계산한다).

## 설정 화면

「모양 › 편집기」 묶음, 이 순서(구현자의 판단 — 거터(줄번호·접기 표시) → 글 모양(줄 바꿈·들여쓰기) → 글꼴 → 상태 표시줄):

1. 줄번호 표시(체크)
2. 접기 표시(체크)
3. 줄 바꿈(체크)
4. 들여쓰기(고르개: 공백 2 · 공백 4 · 탭)
5. 글꼴 크기
6. 글꼴
7. 글자 수 보이기(체크)

설정 설계(`docs/superpowers/specs/2026-10-20-tote-notes-settings-and-shortcuts-design.md`) 3절 「모양」 의 묶음 문장을 이 목록으로 고쳤다.

settings.json 의 `editor` 에 넷을 더한다(`src-tauri/src/appdata.rs` `EditorSettings`). 패치 이름은 `SettingsPatch` 의 기존 꼴(`editor` + 필드).

| 키                  | 값                                | 기본         | 잘못된 값(`lenient`) | 패치               |
| ------------------- | --------------------------------- | ------------ | -------------------- | ------------------ |
| `editor.wrap`       | bool                              | `true`       | `true`               | `editorWrap`       |
| `editor.indent`     | `"spaces-2"`·`"spaces-4"`·`"tab"` | `"spaces-2"` | `"spaces-2"`         | `editorIndent`     |
| `editor.charCount`  | bool                              | `false`      | `false`              | `editorCharCount`  |
| `editor.foldGutter` | bool                              | `true`       | `true`               | `editorFoldGutter` |

필드가 없거나 모양이 틀리면 그 필드만 기본값으로 읽는다(다른 편집기 설정은 살린다). 패치의 `editorIndent` 가 세 값 밖이면 패치 전체를 거절한다(`bad-request`, `themeMode`·`sidebarSort` 와 같다). 세션에는 아무것도 더하지 않는다.

- 「편집기」 절에 이 문서를 가리키는 줄.
