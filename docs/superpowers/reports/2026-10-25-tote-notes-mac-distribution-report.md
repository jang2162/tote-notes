# tote-notes macOS 배포 — 병합 보고

설계 `docs/superpowers/specs/2026-10-25-tote-notes-mac-distribution-design.md`, 계획 `docs/superpowers/plans/2026-10-25-tote-notes-mac-distribution.md` 을 실행한 결과다. 사람이 할 일(비밀 등록·업데이트 키·태그)은 `docs/guides/release-macos.md` 에 있다.

## 판정

- 구현 11 태스크 → 앱·빌드 리뷰(앱 「수정 후 병합」, 빌드 「병합 가능」) → 수정 회차 → 재리뷰 「병합 가능」 → 화면 확인 합격(불합격 0).
- 화면 확인은 임시 서명·hardened runtime 번들 두 벌로 실제 업데이트(0.0.1 → 0.1.0)를 돌렸다. 새 판이 인자 없이 다시 떴고, 마지막 키 뒤 약 325ms(500ms 저장 타이머 전)에 재시작 라운드가 메모를 썼고, `tote --import` 로 띄운 실행을 업데이트해도 메모는 하나였다. 메뉴 「tote 종료」 는 세 경우 모두 다시 뜨지 않았다.

## 첫 릴리스

`v0.1.0` 태그 실행(<https://github.com/jang2162/tote-notes/actions/runs/40257394866>)이 모든 단계를 통과해 공개됐다. 받은 DMG 와 그 안의 앱은 `spctl` 이 `Notarized Developer ID` 로 받아들였고 `stapler validate` 도 통과했다. 로그인 없이 받은 `releases/latest/download/latest.json` 은 버전 0.1.0 과 두 플랫폼 주소를 담았다. 넘기는 것 표에 있던 「첫 태그 실행의 캐시 경로」 는 이 실행으로 닫혔다.
