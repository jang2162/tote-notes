# tote-notes 앱 다듬기 — 병합 보고

0.1.0 공개 뒤 사람이 말한 네 가지와 그 뒤 한 가지(영상 빠른 거절)를 `jang2162/app-polish`(`7e44851..4d173f3`, 커밋 22개)로 고쳐 병합했다.

## 무엇이 바뀌었나

- **Finder 등에서 연 파일.** macOS 의 파일 열기 이벤트(`RunEvent::Opened`)를 받아 `tote <파일>` 과 같게 외부 탭으로 연다. 꺼진 앱이 파일로 켜질 때는 setup 전에 온 URL 을 모았다가 연다. `fileAssociations` 는 Editor·`Alternate`. `.ts`·`.mts` 는 macOS 가 내용과 상관없이 MPEG-TS 영상 형식으로 보므로 선언에서 뺐다(TypeScript `.ts` 는 「기타…」 나 기본 앱 지정으로 열린다). 근거는 코어 스펙 「`tote` CLI」 절.
- **앱 이름 `Tote Notes`.** 번들·메뉴·DMG·업데이트 묶음. 실행 파일 이름(`tote`), 식별자, 셸 명령, 데이터 폴더는 그대로. 릴리스 자산은 `Tote-Notes_<버전>_universal.*`. 0.1.0(`tote.app`)에서 업데이트하면 Finder 파일 이름만 `tote` 로 남는다(`docs/guides/release-macos.md`).
- **기본 워크스페이스 루트 `~/.tote`**(디버그 `~/.tote-dev`). 설정에 루트가 없고 옛 기본(`~/Tote`)에 워크스페이스가 있거나 그 루트·그 안의 워크스페이스를 지금 읽지 못하면 한 번 `~/Tote` 로 고정한다. `tote -w` 도 같은 판정을 쓴다.
- **설정 화면 포커스 링.** 스크롤 상자인 `.settings-panel` 이 가장자리 링을 잘랐다. `--focus-ring-room` 만큼 안쪽 여백·음수 바깥 여백·`scroll-padding`.
- **텍스트가 아닌 파일은 앞 8KB 로 거절.** 외부 탭·메모·대용량 뷰어·외부 변경 감지가 통째로 읽기 전에 `persist::is_binary` 로 판정해 「텍스트로 열 수 없음」. 영상으로 바뀐 메모에서 「디스크 버전」 뒤 창을 닫으면 버린 텍스트가 영상 위에 쓰이던 길도 막혔다.
- **훅.** `lefthook.yml` pre-push 에 vitest 전체.

## 줄번호 클릭 선택(같은 날 추가)

`jang2162/line-select`(`600c316..24828b1`). 줄번호 클릭은 그 줄을, 끌기는 지나간 줄들을(자동 스크롤), ⇧ 클릭은 줄 단위로 넓힌다. 본문 선택에서의 ⇧ 클릭은 VS Code 소스처럼 기준점을 그 자리에 두고 머리만 줄 단위로 옮긴다. 끄는 도중 글이 바뀌면 끌기를 끝낸다. 동작은 설정·단축키 스펙의 줄번호 절. 같은 브랜치에서 실제 시계에 기대던 vitest 두 파일(`search-count`, `tokenizer`)을 고정 시계로 바꿨다 — pre-push 의 vitest 가 부하 높은 맥에서 push 를 막았다. 리뷰(「수정 후 병합」) → 수정 → vitest 433, cargo 455, e2e 447.
