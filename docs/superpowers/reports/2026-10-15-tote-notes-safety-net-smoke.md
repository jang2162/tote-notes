# tote-notes 안전망 — 스모크 (2026-10-15)

안전망 계획 「Task 17: 에이전트 화면 스모크」(에이전트 절)와 「Task 18: 사람 스모크」(사람 절)의 기록이다. 이 절은 에이전트가 Orca computer-use 로 실제 `tote-dev` 창을 조작해 확인한 것이다. **사람 절은 Task 18 이 채운다.**

- 번들: 디버그 빌드 `src-tauri/target/debug/bundle/macos/tote-dev.app`(HEAD `fd796f6`), 식별자 `dev.tote.note.dev`.
- 격리: 모든 실행은 `TOTE_DATA_DIR=/tmp/tote-agent-smoke`, `TOTE_BACKUP_INTERVAL_SECS=5`, `TOTE_BACKGROUND` 없이(사전 점검 B2). 시작 전과 끝에 `~/Tote-dev`·`~/Library/Application Support/tote-dev` 가 **없음**을 확인했다. `~/Tote` 는 읽지도 쓰지도 않았다.
- 사람 동의: 「스모크+측정」(코디네이터가 2026-10-14 에 받음).
- 기기: 내장 14인치(메뉴 막대 폭 1512), macOS 27.0.1.

## 도구의 한계 — 결과를 읽기 전에

- **`type-text` 는 편집기(CodeMirror)에서 글을 두 번 넣는다**(`abc` → `abcabc`, 파일에도 그대로 저장). 사이드바 필터 같은 `<input>` 은 한 번만 들어간다. 합성 입력의 이중 전달로 보이며 앱 결함인지는 가리지 못했다(실제 키보드로는 이 머신에서 시험하지 않았다).
- **`paste-text` 는 AX 로 글을 넣은 뒤 ⌘V 로 시스템 클립보드를 한 번 더 붙인다.** 메모에 덧붙은 「출처 불명」 글(`"스모크+측정",`, 1,286바이트짜리 조율 메시지)은 외부 타이핑이 아니라 이 이중 붙여넣기였다 — 당시 클립보드(`pbpaste`)가 정확히 1,286바이트였다. 그 뒤 편집기 입력은 `set-value`(verified)로 했다. 오염된 `alpha lorem ipsum…` 메모는 지우지 않았고 판정 근거로 쓰지 않았다.
- `orca computer click --element-index` 를 **탭 요소**에 하면 탭이 닫힌다(접근성 누르기가 ×에 닿는다). 탭은 좌표나 메뉴(보기 › 다음 탭·이전 탭)로 옮겼다.
- `hotkey`·`press-key` 는 창이 포커스되지 않으면 `window_not_focused` 로 실패했다(`--restore-window` 로도 안 풀릴 때가 있었다). 메뉴 항목은 `osascript` System Events 로 눌렀다(`click menu item … of menu … of menu bar 1 of process "tote"`). 이 경로는 손쉬운 사용 권한이 있어 동작했다.
- **네이티브 대화상자(저장 실패 경고)는 AX 트리·창 목록·`orca` 스크린샷 어디에도 안 나온다.** `screencapture -x -R<창 영역>` 에만 보였고, 단추는 키(Esc = 취소, Tab+Return = 그래도 종료)로 눌렀다. 같은 파일 대화상자(「파일에서 설치…」)는 `⌘⇧G` 로 경로를 넣어 조작할 수 있었다.
- 입력기가 필요한 항목은 시도하지 않았다(Task 18 로).

## 관찰

- **메모 파일은 저장 때 첫 줄로 개명된다**(`aaaa.md` → `external reread of the file contents here.md` 등). 외부 도구가 그 경로를 붙들고 있으면 쓰기가 옛 경로로 가서 **새 메모가 하나 생긴다** — 이번에 시험 방법을 한 번 바꿔야 했다. 스펙 의도인지 확인이 필요하다(코디네이터).
- **저장 실패 경고 대화상자가 화면 캡처에만 보인다.** 접근성·창 목록에서 안 보이므로 에이전트·보조 기술이 응답 못 한다. 대화상자 단추가 `취소` 에 포커스가 가 있다.
- 종료 요청을 겹쳐 보내면(메뉴 + `osascript` + ⌘Q) 대화상자가 **겹쳐 두 개** 뜬 적이 있다. 첫 대화상자가 열린 동안 다른 종료 요청은 무시되는 설계(`asking` 라운드)와 다른 모습이었다. 재현 조건이 불분명해 판정하지 않는다.
- `tote-dev` 가 내 조작 중 한 번 스스로 끝났다: 코디네이터 재개 대기 중 앱이 없었고, 겹친 대화상자 뒤 한 번 더 종료됐다(내 `System Events click` 이 권한 오류로 실패한 직후). 원인은 가리지 못했다.
