# tote-notes 메모 목록 기능 묶음 — 실기기 확인 목록

2026-10-30. 메모 목록 기능 묶음 계획(`docs/superpowers/plans/2026-10-30-tote-notes-memo-list-features.md`)의 구현 워커가 남긴다. 스펙 「테스트」 절의 실기기(WKWebView) 확인 항목 가운데 **워커가 화면으로 보지 못한 것**이다. e2e(`tests/e2e/memo-list.spec.ts`, `FakeBackend`)는 네이티브 팝업을 띄우지 않고(가짜가 고른 id 를 바로 돌려준다) 실제 글꼴로 그리지 않는다.

디버그 번들은 `docs/guides/development.md` 「디버그 앱은 언제나 `TOTE_DATA_DIR` 을 주고 띄운다」 대로 띄운다. 메모가 스무 개 넘는 워크스페이스로 본다(스크롤이 생기게).
