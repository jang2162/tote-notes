# tote-notes 메모 휴지통·줄번호 글자 크기 — 실기기 확인 목록

2026-11-01. 메모 휴지통 계획(`docs/superpowers/plans/2026-11-01-tote-notes-memo-trash.md`)의 마지막 워커가 남긴다. 스펙(`docs/superpowers/specs/2026-11-01-tote-notes-memo-trash-design.md`) 「시험이 보여야 하는 것」 의 실기기(WKWebView) 확인 항목에, **단위 시험·e2e 가 닿지 않는 Rust 접착**을 더했다. e2e(`tests/e2e/trash.spec.ts`)는 가짜 백엔드(`src/backend/fake.ts`)로 돌아 네이티브 팝업을 띄우지 않고(가짜가 고른 id 를 바로 돌려준다), Tauri 명령 본문(`src-tauri/src/app/commands.rs` 의 `trash_memo`·`list_trash`·`read_trashed`·`restore_memo`·`purge_trashed`·`empty_trash`), 창 사이 `tote://trash-memo`·`tote://trash` 전달, 실제 파일 옮기기, 파일 감시, 자동 비우기 타이머를 지나지 않는다.

디버그 번들은 `docs/guides/development.md` 「디버그 앱은 언제나 `TOTE_DATA_DIR` 을 주고 띄운다」 대로 띄운다. 사람의 디버그 앱이 떠 있으면 그 절의 「같은 identifier 의 디버그 앱이 이미 떠 있으면」 항목대로 identifier·productName 을 바꿔 따로 빌드한다. 파일 쪽 확인은 워크스페이스 폴더(`$TOTE_DATA_DIR/workspaces/<이름>`, 아래 `<ws>`)의 `.trash/`·`.tote/index.json` 을 본다.

한 시간 타이머(`src-tauri/src/lib.rs` `start_trash_expiry`)는 화면으로 기다릴 수 없어 「열 때 비우기」(T-11)로 본다. 같은 함수(`AppCore::expire_trash_all`)를 쓰는 타이머 쪽 갈래는 단위 시험 `expire_trash_all_empties_old_items_of_open_workspaces` 가 본다.

## 이번 확인

- 번들: `pnpm tauri build --debug --config src-tauri/tauri.dev.conf.json --config <접미사 Trash 설정>` 으로 만든 `Tote Notes Trash.app`(identifier `com.develma.totenotes.devtrash`), `TOTE_DATA_DIR` 은 임시 폴더. 사람의 디버그 앱·설치본은 건드리지 않았다. 끝난 뒤 `~/.tote-dev`·`~/Tote-dev`·`~/Library/Application Support/tote-dev` 에 기준 파일보다 새 파일이 없었다.
- 앱은 pid 에 `kill -TERM` 으로 껐다(T-11 앞과 끝).
- **확인 중 고친 것:** 설정 「일반」 에서 「휴지통 자동 비우기」 줄이 업데이트 확인 체크와 그 설명 글 사이에 들어가 있어, 설명 글이 휴지통 칸의 것처럼 보였다. 설명 글을 체크 바로 아래로 옮겼다(`src/ui/settings.ts` `generalSection`, e2e `the update check switch saves updates.autoCheck` 에 위치 단언).

## 다시 할 때의 함정

- 네이티브 팝업(문맥 메뉴)은 앱이 맨 앞일 때만 뜬다. 배경 합성 오른쪽 클릭이나 AX 「메뉴 보이기」 로는 아무것도 뜨지 않았다. 창의 빈 곳을 한 번 눌러 앞으로 가져온 뒤 오른쪽 클릭한다. 비활성 창의 첫 클릭은 앞으로 가져오기만 하고 행을 누르지 않는다.
- 뜬 팝업은 이 앱의 AX 트리에 나오지 않았다. 항목은 화면 좌표로 누른다(눌린 자리에서 아래로 약 12·46·70px).
- 합성 키로 ⌘ 조합을 보낸 뒤 수식 키를 놓는 `flagsChanged` 를 보내지 않으면 다음 글자가 ⌘ 조합(⌘A 등)으로 들어간다.
- 앞에 둔 앱을 키 확인 사이에 다른 앱(이번엔 Orca)이 다시 가져가면 키가 사라진다. 키를 보내기 직전에 맨 앞 앱을 확인한다.
