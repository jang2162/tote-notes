# tote-notes 제목 줄 탭·사이드바 접기 — 화면 확인 목록

실제 WKWebView 와 실제 macOS 창 틀(신호등·창 끌기·전체 화면)은 가짜 백엔드 e2e(Playwright WebKit)가 보지 못한다. 아래는 사람이나 화면을 쓸 수 있는 에이전트가 하는 절차와 기대값이다. 「결과」 칸은 확인한 쪽이 채운다(비어 있으면 아직 안 본 것이다).

## 공통 준비

```bash
pnpm tauri build --debug --config src-tauri/tauri.dev.conf.json
S=$(mktemp -d); touch "$S/start-marker"
# 워크스페이스는 앱 밖에서 만든다: $S/workspaces/Alpha/.tote/workspace.json = {"version":1,"id":"<uuid>"} (Beta 도)
open --env TOTE_DATA_DIR="$S" "src-tauri/target/debug/bundle/macos/Tote Notes Dev.app"
```

- 디버그 앱 규칙(`TOTE_DATA_DIR`, 끝난 뒤 `find … -newer "$S/start-marker"` 가 비어 있는지)은 `docs/guides/development.md` 「디버그 앱은 언제나 `TOTE_DATA_DIR` 을 주고 띄운다」 를 따른다.
- 화면을 쓰기 전에 `ioreg -n Root -d1 -a | grep -A1 CGSSessionScreenIsLocked` 가 false 인지 본다.
- 맨 윗줄 높이는 `--top-row-height`(36px), 사이드바 너비는 `--sidebar-width`(240px), 신호등 자리는 `--traffic-lights-width`(80px), 신호등 위치는 `src-tauri/src/app/windows.rs` 의 `TRAFFIC_LIGHTS_X`·`TRAFFIC_LIGHTS_Y`(14, 11)다. 픽셀은 스크린샷(배율 1)으로 잰다.
