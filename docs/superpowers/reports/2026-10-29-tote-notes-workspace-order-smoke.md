# tote-notes 워크스페이스 순서·숨김 — 실기기 확인 목록

설계는 `docs/superpowers/specs/2026-10-29-tote-notes-workspace-order-and-hiding-design.md`, 계획은 `docs/superpowers/plans/2026-10-29-tote-notes-workspace-order-and-hiding.md`. 이 목록은 e2e(Playwright WebKit)가 못 보는 것, 곧 WKWebView·실제 창·Finder 로만 갈리는 것을 사람이 화면으로 확인하는 표다. 자동 검사는 모두 통과했다(vitest 438, e2e 470, cargo 476 + 메뉴 시험 2).

## 준비

디버그 번들은 `pnpm tauri build --debug --config src-tauri/tauri.dev.conf.json` 으로 만든다. 결과는 `src-tauri/target/debug/bundle/macos/Tote Notes Dev.app` 이다. 띄우는 명령 꼴은 `docs/guides/development.md` 「디버그 앱은 언제나 `TOTE_DATA_DIR` 을 주고 띄운다」 를 따른다.

```bash
S=$(mktemp -d)                 # 시험 루트. 확인이 끝나면 지운다
touch "$S/start-marker"
for n in 가 나 다 라 마; do    # 워크스페이스 다섯 개: 루트 아래 폴더 + .tote/workspace.json
  mkdir -p "$S/workspaces/$n/.tote"
  printf '{"version":1,"id":"%s"}' "$(uuidgen)" > "$S/workspaces/$n/.tote/workspace.json"
done
open --env TOTE_DATA_DIR="$S" "<저장소>/src-tauri/target/debug/bundle/macos/Tote Notes Dev.app"
```

끝난 뒤 `find ~/.tote-dev ~/Tote-dev "$HOME/Library/Application Support/tote-dev" -newer "$S/start-marker"` 가 비어 있어야 한다. 아래 표의 「루트」는 앱이 쓰는 워크스페이스 루트(설정 「일반」 에 보이는 폴더)다. 워크스페이스를 더 만들 때도 위 반복문과 같이 폴더와 `.tote/workspace.json` 을 함께 만든다(없으면 열리지 않는다).

## 확인 표

| #   | 확인                                         | 방법                                                                                                                                                     | 기대 결과                                                                                                                                                                       |
| --- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | WKWebView 에서 설정 「워크스페이스」 행 끌기 | 위 준비로 띄운다. 설정(⌘,) → 「워크스페이스」 구역에서 「다」 행을 잡아 「가」 위로 끈다.                                                                | 끄는 동안 놓일 자리에 줄이 보이고, 놓으면 목록이 다 가 나 라 마 로 바뀐다. 고르개(⌃)도 같은 순서다.                                                                             |
| 2   | 「숨김」 체크박스 클릭이 끌기로 새지 않음    | 같은 구역에서 「나」 행의 「숨김」 체크박스를 마우스로 누르고, 트랙패드 탭으로도 한 번 더 눌러 해제한다.                                                 | 행이 끌리거나 자리가 바뀌지 않고 체크만 바뀐다. 숨기면 고르개에서 「나」 가 빠지고 해제하면 돌아온다.                                                                           |
| 3   | 고르개 ⌃ 표시와 흐린 글씨                    | 고르개를 펼친다. 시스템 설정에서 다크·라이트를 바꿔 둘 다 본다.                                                                                          | 각 줄의 ⌃ 표시가 점 다음 맨 오른쪽에 있고, 두 모드 모두 흐린 글씨가 읽힌다. 숨긴 워크스페이스에는 표시가 없다.                                                                  |
| 4   | 창 둘, 한 창에서 순서 바꾸기                 | ⌘N 으로 창을 하나 더 띄운다. 한 창의 설정에서 순서를 바꾼다.                                                                                             | 다른 창의 고르개가 새 순서로 바뀐다(다시 열지 않아도).                                                                                                                          |
| 5   | 루트 바꾸기                                  | 다른 시험 루트 `$S2` 를 위와 같이 만들되 이름을 `A B C` 로 한다. 설정 「일반」 에서 루트를 `$S2/workspaces` 로 바꾼다. 창이 둘이면 둘 다 본다.           | 열린 창의 고르개와 「워크스페이스」 구역이 모두 새 루트의 목록(A B C)으로 바뀐다. 루트를 되돌리면 그 루트에서 정한 순서가 돌아온다(루트마다 순서가 따로다).                     |
| 6   | 순서 파일과 폴더 이름 바꾸기                 | `cat "$S/workspaces/.tote-workspaces.json"`. 이어서 앱을 켠 채 Finder 에서 「라」 폴더 이름을 「라라」 로 바꾸고 설정 「워크스페이스」 구역을 다시 연다. | 파일은 `{"version":1,"order":[{"id":…,"name":…},…],"hidden":[…]}` 꼴로 (id, 이름) 쌍이다. 이름을 바꾼 뒤에도 「라라」 가 「라」 가 있던 자리에 있다. 숨겼던 것은 숨김이 남는다. |

## 이 목록이 보지 않는 것

- 다른 기기 동기화로 순서 파일이 바뀌는 경우(설계가 파일을 감시하지 않는다고 정했다).
- Finder 에서 복제해 같은 id 를 가진 폴더 둘의 숨김 갈림(화면 확인 행이 없다).
